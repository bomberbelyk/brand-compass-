# Product Brief: Request Architect

## Product

Request Architect is a web service that helps clients formulate unclear project requests through a deep AI interview.

It turns a conversation into professional project documents:

- client brief
- creative brief
- technical specification
- scope of work
- acceptance criteria
- risk report
- executive summary

## Core Problem

Clients often start projects with vague requests:

- "I want a modern website"
- "Make it beautiful"
- "It should look expensive"
- "Make it like Apple"
- "I need an app, but it is hard to explain"

This causes unclear expectations, long discovery calls, shallow briefs, endless revisions, and subjective acceptance.

## Goal

Create a service that:

- conducts a smart interview with the client
- supports Ukrainian and English in the MVP
- unpacks the initial request
- identifies gaps and contradictions
- creates a clear brief and project scope
- helps the client understand their own expectations
- helps the contractor estimate and start the work faster
- fixes acceptance criteria before production begins

## Experience Principle

The client should feel that the interviewer understands them and is guiding them through the exploration.

The interview should not feel like a static form. It should feel like a thoughtful conversation where the system remembers the client's words, reflects their intent, notices uncertainty, and helps convert vague expectations into project decisions.
