# Core User Flow

1. User opens the site.
2. User signs up or logs in.
3. User creates a project.
4. User chooses a project type.
5. User enters the initial vague request.
6. The AI interview starts.
7. The AI asks one adaptive question at a time.
8. The system analyzes each answer.
9. The clarity map is updated after each answer group.
10. The system detects vague language, missing information, and contradictions.
11. The interview is completed.
12. The system generates project documents.
13. User reviews, edits, copies, and exports documents.
