# Clarity Scoring

Each clarity area has a score from 0 to 100.

## Score Bands

- 0-20: missing
- 21-45: weak
- 46-70: partial
- 71-90: clear
- 91-100: strong clear

If a contradiction is detected in an area, the status becomes `conflict`.

## Areas

- goal
- audience
- business context
- result
- style
- references
- timeline
- budget
- constraints
- stakeholders
- acceptance criteria
- risks
- scope
- tone of voice
- technical requirements

## MVP Colors

- missing: gray
- weak: red
- partial: yellow
- clear: green
- conflict: purple
